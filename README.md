# ISPSC — واجهة المزارع (Frontend فقط)

نسخة مستقلة من منصة ISPSC فيها صفحات المزارع بس، من غير باك اند ومن غير تسجيل دخول.
كل البيانات تجريبية (Mock) وشغالة في الذاكرة.

## التشغيل
```bash
npm install
npm run dev
```
هيفتح على لوحة تحكم المزارع مباشرة (`/dashboard`).

## ملاحظات
- البيانات التجريبية في `src/lib/mockData.js`، والعميل التجريبي في `src/lib/supabase.mock.js`.
- أي إضافة أو تعديل بتعمله (قطعة، رسالة، طلب...) بيفضل لحد ما تعمل Refresh.
- لما تربط باك اند حقيقي: غيّر `src/lib/supabase.js` ليرجع `createClient` الحقيقي، وامسح ملفي الـ mock.
- الطقس بيجيب بيانات حقيقية من Open-Meteo (محتاج إنترنت)، وده الشيء الوحيد اللي بيتصل بالخارج.
